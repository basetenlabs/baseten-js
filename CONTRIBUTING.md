# Contributing

## Setup

```bash
npm install
```

## Tasks

- `npm run generate-api` - Regenerate API clients and models from OpenAPI specs (pass `-- --update-specs` to download latest specs first)
- `npm run build` - Build the package
- `npm run format` - Format code and auto-fix lint issues
- `npm run lint` - Check formatting, lint, and type-check
- `npm test` - Run tests
